What it does

An assistant that does things, not one that explains how you could.

Every feature is a tool the model can call on your behalf. You stay in the loop where it matters, like sending email, and out of the loop where it doesn't.

Chat that acts

"Move gym to 8", "what's on this week", "book 30 minutes with Ayşe on Friday". It checks the calendar first, then does it, then tells you in one line.

Email drafts you approve

It reads the thread and writes a reply like a real person. The draft lands in the chat with Send, Keep and Delete. Nothing leaves without your tap.

Calendar that checks itself

Reads, adds, moves and deletes events. Keeps the duration when you only move the start. Never books over something else without saying so.

A to-do list you both keep

"I need to renew my Oyster card" goes on the list. "Done with the report" ticks it off. You add and tick things in the To-do tab and it updates live. It offers to add deadlines it spots in email.

Reminders and a morning brief

"Remind me at 6 to call mum." Reminders survive restarts. Every morning at 7:45: your schedule, emails to deal with, and what's due this week.

Memory you can see and edit

Lasting facts you mention ("I train Mon, Wed, Fri", "Kerem is my flatmate") are saved and used in every chat. The Memory tab shows all of them. Remove any with one tap.

Voice notes and photos

Hold the mic and talk, in English or Turkish. It shows what it heard, then acts. Send a screenshot of a timetable or a poster and it pulls out the dates.

Inbox watch

Every 20 minutes it looks at new mail with a cheap, fast model and pings you only when something matters: a real person, an interview, a deadline. Newsletters stay quiet.

How it works

Three parts. You own all of them.

The phone app, Telegram and WhatsApp are just doors into one assistant. Every door shares the same memory, the same to-do list and the same conversation.

  1. 1

    You talk

    From the app, Telegram or WhatsApp. Text, a voice note or a photo. Commands like /brief and /todo work everywhere.

    AppTelegramWhatsApp
  2. 2

    Your server thinks

    A small Python service runs Claude with a set of tools: calendar, Gmail, to-dos, reminders, memory, web search. Quick questions go to Sonnet, careful writing goes to Opus.

    PythonClaudeSQLite
  3. 3

    Your accounts act

    Changes land in your Google Calendar and Gmail drafts. The reply comes back over a live connection to the app, or as a notification when it's closed.

    GmailCalendarPush

Live, not polling

Replies arrive the moment they're ready.

The app keeps a WebSocket open to your server. You see a typing indicator for exactly as long as the assistant is working, replies stream in as they land, and the To-do tab updates the second the assistant changes the list. When the phone has been asleep, the app notices a stale connection and reconnects on its own.

  • Typing indicator driven by the server, not a timer
  • Messages carry an id, so nothing doubles or goes missing
  • History on the server: open the app on another device and it's all there
  • Push notifications when the app is closed

Privacy and control

Self-hosted means exactly that.

There is no company in the middle. Your messages, memories and to-dos sit in a small database on a server you rent for about $5 a month. The only things that leave it are the API calls you'd expect.

Your keys, your bills

You bring your own Claude API key and Google credentials. Usage shows up on your own account, with no markup and no middleman.

Nothing is sent without you

Email is draft-only by design. Every draft needs a tap on Send. Calendar changes are confirmed in one line so you can undo them.

One owner

It only answers you. Messages from anyone else on Telegram or WhatsApp are ignored. The app authenticates with a long random token you generate.

Memory you can audit

Everything it remembers is listed in the Memory tab. Delete a fact and it's gone from every future conversation.

Open source

Around two thousand lines of readable Python and TypeScript. You can read every tool the model is allowed to use and change any of them.

Cheap to run

Prompt caching keeps multi-step requests cheap. Expect £3 to £10 a month in API use for normal personal traffic, plus hosting.

The app

Four tabs. Nothing you don't need.

Built with Expo for iPhone and Android. Light and dark, haptics, hold-to-talk, and a draft card that remembers what you did with it.

Setup

About half an hour, once.

The README walks through each step with screenshots. Here's the shape of it.

  1. 3 min

    Claude API key

    Create a key at console.anthropic.com and add a few pounds of credit.

  2. 15 min

    Gmail and Calendar access

    Make a Google Cloud project, enable the two APIs, run the one-off sign-in script. It stores a refresh token for the server.

  3. 10 min

    Deploy

    Click "Deploy from GitHub" on Railway, paste your variables, attach a small volume for the database. Done.

  4. 2 min

    App token

    Generate a long random token, set it as APP_TOKEN, and put the same value in the app's Settings.

  5. optional

    Telegram or WhatsApp

    Add a bot token for Telegram, or connect a WhatsApp Business number. Both share the same assistant.

.env
# the brain
ANTHROPIC_API_KEY=sk-ant-…
SONNET_MODEL=claude-sonnet-5-5

# your Google account (from auth_google.py)
GOOGLE_TOKEN_JSON={"refresh_token": "…"}

# the phone app
APP_TOKEN=a-long-random-secret-at-least-20-chars

# optional
TELEGRAM_BOT_TOKEN=…
TRANSCRIBE_API_KEY=sk-…      # voice notes
TIMEZONE=Europe/London

Under the hood

The right model for each message.

Quick lookups and small edits go to Sonnet. Drafting, planning, advice, long messages and photos route to Opus. The inbox watch uses Haiku, which costs almost nothing. The system prompt and tool list are cached across calls, so a request that takes four tool calls costs barely more than one.

  • Sonnet and Opus routing, or pin one model
  • Prompt caching on the stable part of the prompt
  • Turns queue one at a time, so nothing races
  • Tool failures are reported back to the model, which tells you in one line

FAQ

Questions people ask first.

Is this a product I sign up for?

No. It's a repository you deploy. There's no account, no subscription and no server of ours. You run it, you own it.

Can it send email on its own?

No, and that's deliberate. It can read and search Gmail and write drafts. Every draft comes to you with Send, Keep and Delete. Sending always needs your tap.

Do I need to use the app? I like Telegram.

Use whichever you like, or several. The app, Telegram and WhatsApp are channels into the same assistant and the same memory. Proactive messages like reminders go to the channel you used last.

What does it cost to run?

Roughly £3 to £10 a month in API use for normal personal traffic, plus about $5 for hosting on Railway. Voice notes add about 0.3p a minute with OpenAI, or nothing on Groq's free tier.

How do notifications work when the app is closed?

Through Expo's push service. It needs a development build of the app rather than Expo Go. Android builds are free. iPhone needs an Apple Developer account.

Can other people use my instance?

Not yet. It is built for one owner and ignores everyone else. The code is structured so that accounts can be added later: auth is one function, and messages are already keyed by chat.

Which languages does it understand?

Anything Claude does. Voice notes are transcribed with Whisper, which handles English and Turkish well, among many others.
